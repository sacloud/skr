# ADR 0057: Object Storage 管理 API コマンドを追加する

- Status: Accepted
- Date: 2026-10-23

## Context

`sacloud-sdk-go v0.3.1` は Object Storage のサイト、サイトアカウント、バケット、パーミッション、状態取得の API を公開しています。これらを `skr` から利用できるようにします。

オブジェクトストレージの管理 API と S3 互換 API は別の操作範囲です。対象 SDK の `api/object-storage` は管理 API を提供し、オブジェクト本体の S3 操作は対象外です。アクセスキーのシークレットは発行時の応答にのみ含まれます。

## Decision

- `skr object-storage-api` を追加し、コマンドを `internal/objectstorageapi/` に配置します。サイト、アカウント、バケット、パーミッションの SDK 公開操作を対象にします。
- 公開 SDK の API interface を呼び出し、IaaS／Ogen 系コマンド生成器には載せません。管理 API にはサービス固有の高レベル interface があるため、API クライアントの作成と複数操作の呼び出しを手書きで接続します。
- サイト ID は各サイトスコープの操作で位置引数として受け取ります。バケットの作成・削除、暗号化、レプリケーション、利用量取得は対象バケットを位置引数で指定します。
- SDK 内でサイト非依存となるバケット削除とレプリケーション操作は、実行前に指定サイトのバケット一覧で所属を確認します。所属不明や照会失敗では後続の操作を拒否します。
- 出力式は全コマンドの API 呼び出し前に検証し、不正な式でキー発行や設定変更だけが実行されることを防ぎます。
- パーミッションの作成・更新は `display_name` と複雑な `bucket_controls` を含む SDK モデルの JSON を受け付けます。SDK のモデルをそのままデコードし、`--request` は `@path.json` または直接 JSON を使えます。
- アクセスキーのシークレットを入力引数にしません。作成 API の返却値として出力される場合だけ利用者に表示します。`--trace` を有効にすると API の応答本文を記録します。アクセスキー発行時にシークレットも記録されるため、`--trace` を有効化しないようルートヘルプで警告します。
- バケット作成は課金を伴うため、CLI のヘルプとチュートリアルで課金開始と空でないバケットを削除できないことを説明します。
- S3 互換 API によるオブジェクトの一覧・取得・アップロード・削除はこのコマンドの対象外です。これらはオブジェクトストレージ管理 API と異なる認証・通信方式を持つため、S3 対応 SDK の採用を別途判断します。
- API interface を差し替える単体テストに加え、sakumock の `objectstorage` サーバーを使い、CLI と公開 SDK の HTTP 通信を含めて全サブコマンドを検証します。明示的な確認フラグを要求するライブ E2E runner も用意します。ライブ E2E は料金影響を確認し、承認された環境でのみ実行します。

## Consequences

- 公開管理操作を CLI から実行できます。認証と出力には既存の SDK プロファイルと共通 JSON 出力を使います。
- オブジェクト本体を扱う S3 API クライアント機能は別途実装が必要です。
- バケット作成やキー発行など副作用を伴う操作が利用可能になります。ライブ E2E の実行には、課金や認証情報の発行を含む影響を事前に確認する必要があります。
- アーカイブ用サイトのバケット作成では SDK の変換補助入力 `Plan` を `--plan` として受け付けます。`site plans` の結果から指定する値を確認できます。

## Alternatives considered

- Ogen API コマンド生成器で操作を生成する案は採用しません。対象 SDK は Ogen 生成クライアントに加えて管理操作用の独自 interface と変換ロジックを提供しており、共通生成器の設定だけではSDK操作の形を正確に表現できないためです。
- S3 互換 API 操作もこの変更に含める案は採用しません。対象 SDK の管理 API ライブラリの範囲外であり、別の API クライアントと認証情報を必要とするためです。
- バケット削除時に中身を自動削除する案は採用しません。バケット内オブジェクトやフォルダの削除はユーザーが確認して個別に行う必要があります。
