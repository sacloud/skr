# ADR 0030: table 出力を廃止し JSON とクエリに統一する

- Status: Accepted
- Date: 2026-10-07

## Context

table 出力では列の優先順位、端末幅、表示幅、値と列の省略、日時の表示、全ゾーン検索の Zone 列などを保守しています。社内では table の需要を疑問視する意見があり、保守負担に見合う必要性を確認できていません。開発中のプロダクトとして、互換性維持より出力処理の簡素化を優先します。

`--query` は既に API 結果を jq 式で加工し、JSON で返します。一覧の確認に必要な ID、名前などを投影すれば、table を使わずに短い結果を表示できます。

## Decision

- API の結果は JSON のみで出力します。`--output` 自体を削除し、非推奨期間や互換用の指定は設けません。
- `cli.default_output_type` と `DefaultOutputType` は参照しません。出力形式のためのプロファイル読み込みは削除しますが、認証とプロファイル機能は維持します。
- E2E とチュートリアルの表示用一覧は、`--query` で必要な項目を投影した JSON を使います。空一覧は `[]` として確認できる式を選びます。安全性検証と後始末に必要な情報は削りません。
- Runtime は出力の事前検証と JSON 書き込みを受け取ります。無効なクエリは、結果を返す操作の API 呼び出し前に拒否します。
- 全ゾーン検索の table 専用ラベルを削除します。通常 JSON の形状、結果集約、失敗時の部分出力抑止は維持します。
- 既存 E2E の実環境検証では IaaS の作成先を `is1b` に揃えます。Switch runner には既存リソースを事前に削除しない、ランダム名の実行経路を追加します。Sandbox 用の既存経路は維持します。
- [ADR 0009](0009-api-output-formats.md) の形式選択、[ADR 0013](0013-tutorial-list-output.md) の table 原則、[ADR 0025](0025-jq-output-filter.md) の出力形式の優先順位、[ADR 0028](0028-remove-yaml-output.md) の JSON と table の併存を置き換えます。出力例の根拠確認やクエリの評価方針など、その他の決定は維持します。

## Consequences

- 列幅や表示用ラベルを保守する必要がなくなります。生成器、生成コード、手書きハンドラーを同じ出力契約に揃えます。
- `--output json`、`--output table`、`--output yaml` はいずれも未対応フラグとしてエラーになります。
- 旧プロファイルの出力形式設定は出力に影響しません。設定ファイルを自動で書き換える移行処理は追加しません。
- 一覧の読みやすさは、確認したい項目を明示するクエリで確保します。チュートリアルと E2E では JSON の構造と値を確認し、表示文字列の包含だけでは成功と判定しません。

## Alternatives considered

- table を維持する方法: 表示処理の保守負担を減らす目的に合わないため採用しません。
- `--output json` だけを残す方法: 選べる形式がないため採用しません。
- 非推奨期間を設ける方法: 開発中のプロダクトで互換性維持を必要としないため採用しません。
- E2E の全出力を投影する方法: 安全性検証に必要な情報を落とす危険があるため、表示用一覧に絞ります。
