# ADR 0048: 生成コマンド名を設定で明示する

- Status: Accepted
- Date: 2026-10-15

## Context

IaaS API コマンド生成器は Go の操作名から Kong コマンド名を生成します。略語や大文字小文字が混在する操作名は、意図した kebab-case と異なる名前になる場合があります。たとえば `ReadIPv6` は `read-ipv-6` となり、利用者向けの `read-ipv6` と一致しません。

## Decision

- IaaS API 生成設定の操作に任意の `command_name` を追加し、利用者向けコマンド名を kebab-case で明示できるようにします。
- `command_name` を使う設定では、すべての操作に一意な名前を指定します。省略時は既存どおり Go フィールド名から Kong が生成する名前を使います。
- 生成器は名前の形式と重複を検証し、生成されるコマンドフィールドに明示的な Kong `name` を設定します。

## Consequences

- 略語を含む API 操作にも安定した利用者向けコマンド名を割り当てられます。
- 明示名を使う設定には、各操作の CLI 名を列挙する記述が増えます。
- 既存設定は変更せず、既定のコマンド名も変わりません。

## Alternatives considered

- 不自然な既定名をそのまま公開する方法: 利用者向け構文を明確にできないため採用しません。
- SDK 操作名を変更する方法: SDK インターフェースとの対応が分かりにくくなるため採用しません。
- `internal/cli` に別名のラッパーコマンドを手書きする方法: 生成されたコマンド階層との二重管理を避けるため採用しません。
