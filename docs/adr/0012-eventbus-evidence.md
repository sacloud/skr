# ADR 0012: EventBus E2E 証跡の保存先と順序

- Status: Accepted
- Date: 2026-10-05

## Context

EventBus E2E の証跡は OS の一時ディレクトリに保存されていました。実行のたびに異なる場所へ出力されるため、ユーザーがログを見つけにくく、操作を記録した JSON ファイルの実行順も名前から判断できませんでした。

この ADR は [ADR 0011](0011-eventbus-live-e2e.md) の証跡保存先に関する決定を更新します。ライブ E2E の対象範囲、安全確認、秘密情報の扱いは変更しません。

## Decision

- 証跡をリポジトリルートの `tmp/eventbus-api/<YYYYMMDDHHmm>/` に保存します。このパスは `.gitignore` に追加し、Git の変更として扱いません。
- 証跡ディレクトリは `0700`、JSON と索引ファイルは `0600` にします。API キー発行結果の stdout は従来どおり `[REDACTED: APIKey]` に置き換えます。
- CLI 呼び出しごとに単調増加する3桁の連番を付け、`<連番>-<操作名>.json` として保存します。`ORDER.txt` にも実行順、操作名、成否、対応ファイルを記録し、`RESULT.txt` に最終結果を記録します。
- 同じ分に実行を重ねる場合は `-02` 以降を付け、既存の証跡を上書きしません。

## Consequences

- E2E の実行後に出力されるパスから、コマンドの stdout、stderr、引数、実行順を追いやすくなります。
- 証跡にはプロジェクト ID やリソース ID が含まれる場合があるため、ローカルで確認し、共有やコミットはしません。
- 実行後に証跡を削除する場合は、表示された実行ディレクトリを個別に削除します。

## Alternatives considered

- OS の一時ディレクトリを継続する方法: 実行後に場所を見失いやすいため採用しません。
- 操作名だけのファイル名を使う方法: 同じ操作の再試行を区別できず、実行順が分からないため採用しません。
