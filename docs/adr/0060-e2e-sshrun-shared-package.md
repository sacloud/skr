# ADR 0060: E2E の SSH 待機とログイン確認を共通パッケージに集約する

- Status: Proposed
- Date: 2026-10-26

## Context

server / internet / gslb のライブ E2E runner は、それぞれ `waitForSSH` と SSH ログイン確認の実装を重複して持っていました。タイマーとポーリングによる待機ループ、`ssh` コマンドの引数構成（秘密鍵、`BatchMode`、`ConnectTimeout` など）、ログイン確認の成功判定、evidence への記録は runner ごとで微妙に異なりました。そのため修正のたびに複数箇所の編集と確認が必要でした。

また、待機中のポーリングは状態確認のための `test-read` コマンドと失敗した SSH 試行を個別に evidence に記録していました。そのため `REPORT.md` が待機の試行回数分のノイズで埋まり、待機全体の要約（何分待機して何回確認したか）を読み取れませんでした。

## Decision

- SSH の待機・ログイン確認・リモートコマンド実行を `test/e2e/internal/sshrun` パッケージに集約します。`evidence` パッケージと同じ立ち位置の共有パッケージとします。
- `sshrun.Runner` は `Recorder`、`PrivateKey`、`KnownHosts`、差し替え可能な `SSH` 関数を受け取ります。`Wait` はタイマーとポーリングで `Probe` を繰り返し、`ProbeLogin` はリモートで `hostname` を実行してログインを確認します。`Run` は電源操作などの個別のリモートコマンド実行に使います。
- 待機中はポーリングごとの `test-read` や失敗した SSH 試行を evidence に記録しません。待機の結果を 1 件の要約レコード（待機時間と確認回数を含む説明と、最後の確認内容）として記録します。`Run` のコマンド実行は従来どおり個別に記録します。
- 待機の説明は `Wait` の呼び出し元で渡します（[ADR 0059](0059-e2e-evidence-call-site-descriptions.md) の方針に従います）。タイムアウト・キャンセル・エラーの種別はレコードのエラーとして区別します。
- 待機中に evidence の記録自体が失敗した場合は、待機を打ち切ってエラーを返します。E2E は後片付けを行ったうえで失敗します。
- runner は `observe`（記録しない状態確認）と `call`（記録する操作）を分け、待機中の確認は `observe` を使います。待機の結果だけが証跡に残ります。
- この移行は server / internet / gslb の runner に適用します。`networking-suite` は `ubuntu` ユーザーと NIC の同一性確認など要件が異なるため今回の対象外とし、必要になれば別途移行を検討します。
- 秘密鍵と cloud-config の内容は evidence に記録しません。コマンドの引数と応答だけを記録します。

## Consequences

- SSH 待機の挙動（タイムアウト、ポーリング間隔、ログイン確認、evidence 記録）を 1 か所で修正できるようになります。
- `REPORT.md` の待機部分が要約 1 件になり、待機時間と確認回数を読み取れます。ポーリングごとの応答は証跡に残らなくなります。
- runner の状態確認用 CLI 呼び出しは記録の有無で 2 種類になり、runner と共有パッケージの両方に単体テストが必要になります。
- `networking-suite` は従来の独自実装を維持するため、SSH 待機の挙動が runner 間で一時的に異なります。

## Alternatives considered

- 各 runner の重複を維持する案は採用しません。挙動の差異が蓄積し、修正漏れと確認コストが増えるためです。
- 待機中もポーリングごとの記録を維持する案は採用しません。レポートが試行回数分のノイズで埋れ、待機の要約が読み取れなくなるためです。
- ポーリングごとの応答を要約レコードにすべて埋め込む案は採用しません。最後の確認内容だけを残すほうがレポートを読みやすく、記録サイズも予測できるためです。
- `networking-suite` も同時に移行する案は採用しません。`ubuntu` ユーザー、NIC の同一性確認、複数サーバーの順次確認という固有の要件があり、今回の共通化の範囲を超えるためです。
