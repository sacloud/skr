# ADR 0013: チュートリアルに一覧・検索結果を掲載する

- Status: Accepted
- Date: 2026-10-05

## Context

チュートリアルでは `list` や `find` のコマンドを使ってリソース作成や削除を確認する手順でも、出力例を掲載していない場合がありました。読者がコマンド実行後に何を確認すればよいか分かりにくく、手順が期待どおりに動いたか判断しづらくなります。

## Decision

- 一覧・検索結果で作成、更新、削除などの動作を確認する場合は、対応するコマンドの近くに出力例を掲載します。
- 出力例は確認済みの CLI 出力を基にし、ID、名前、説明、時刻など環境固有の値をマスクまたはプレースホルダーに置き換えます。編集した出力例であることを明記します。
- 結果が空であることを確認する場合は `No results` や `[]` などの出力も掲載します。全件一覧の一部を抜粋する場合や、端末幅で列・値が省略される場合は、その範囲と条件を説明します。
- 見た目だけの成功出力を作らず、現在の CLI 出力、保存された実行証跡、または検証済みの出力形式を根拠にします。

## Consequences

- チュートリアルで期待結果と確認対象が明確になります。
- 出力例の追加により文書は長くなります。環境固有情報を除去し、表示形式の変動も説明して安全性と正確さを保ちます。

## Alternatives considered

- コマンドだけを示し、読者に期待出力を推測してもらう方法: 動作確認手順が曖昧になるため採用しません。
- 固定の実環境出力をそのまま掲載する方法: アカウント固有情報の漏えいと環境差による誤解につながるため採用しません。
