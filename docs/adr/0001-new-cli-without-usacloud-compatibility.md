# ADR 0001: 従来の usacloud との互換性を保証しない

- Status: Accepted
- Date: 2026-10-05

## Context

`usacloud` は 2017 年から続くプロダクトであり、長年の利用と開発を通じて過去の経緯が積み重なっている。一方、AI 時代の開発・運用においては、よりモダンな設計が求められている。

また、`usacloud` はコマンド名がやや長く、より短い名前にすることで日々の利用をしやすくしたい。新しい CLI のコマンド名を `skr` の 3 文字とし、設計を見直すこのタイミングで、従来の制約に縛られず非互換の変更を取り入れられるようにする。

## Decision

さくらのクラウド向け CLI の新しいバージョンを `skr` として開発する。従来の `usacloud` との互換性は保証せず、よりモダンな設計を目指すうえで必要な非互換の変更を許容する。

## Consequences

- 従来の `usacloud` との互換性を前提条件として設計・実装する必要はない。
- 互換性を保つ機能があっても、互換性を保証するものではない。
- コマンド名を `skr` とすることで、より短い名前で利用できる。
- 従来の `usacloud` からの移行では、コマンドや設定などに変更が必要となる場合がある。
- 互換性に関するユーザー向けの説明では、この方針を明示する。
