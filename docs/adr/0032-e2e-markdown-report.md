# ADR 0032: E2E 実行レポートを Markdown で生成する

- Status: Accepted
- Date: 2026-10-08

## Context

E2E はコマンドごとの stdout、stderr、エラーを JSON で保存します。実行内容を確認するには JSON ファイルを順番に開く必要があり、全体の結果や各 CLI 呼び出しの終了コードも一目で確認できません。

## Decision

- 共通の `test/e2e/internal/evidence` が実行完了時に `REPORT.md` を生成します。
- レポートには実行全体の結果と完了日時を示し、各操作の結果と終了コードを一覧します。
- 詳細には実行コマンド、stdout、stderr、実行エラーを記録します。出力を秘匿する既存の操作では、JSON 証跡と同じマスク済み出力をレポートにも使います。
- レポートは他の E2E 証跡と同じ非公開ディレクトリに mode `0600` で保存し、既存の JSON 証跡も維持します。

## Consequences

- JSON を個別に開かなくても、1つの Markdown ファイルでコマンド実行結果を確認できます。
- レポートはコマンド引数や出力などの機微情報を含む可能性があります。証跡と同様に共有・コミットしません。
- コマンドを起動できず終了コードを得られない場合は、レポートで終了コードを「取得できません」と表示し、実行エラーを別途示します。

## Alternatives considered

- JSON 証跡を Markdown に置き換える方法: 既存の構造化証跡を利用するテストや調査手順を壊すため採用しません。
- 各 E2E に個別のレポート生成を実装する方法: 表示形式や秘匿処理が不統一になるため採用しません。
