# 利用者向けドキュメントの構成

## 目的

API チュートリアル以外の解説も含めて利用者向け文書をまとめ、コマンド横断の機能や設定についても見つけやすくします。

## 配置

- `docs/manual/` は利用者向けドキュメントのルートです。
- API を使った具体的な操作手順は `docs/manual/tutorials/` に配置します。
- `--zone` やプロファイルなど、複数のコマンドに関係する機能の解説は `docs/manual/` 直下に配置します。
- `docs/design/`、`docs/adr/` など開発者向けの設計記録は利用者向けマニュアルに含めません。

## 執筆方針

利用者向けの説明は、確認済みの CLI の動作と公式サービス仕様を記述します。コマンド固有の構文は `--help` と実装を確認し、サービス仕様には公式マニュアルや SDK ドキュメントへの参照を添えます。
