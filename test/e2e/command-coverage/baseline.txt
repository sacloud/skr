# status は live(ライブ検証済み) / implemented(実装済み・ライブ未実施) / deferred(延期) / todo(未整備) のいずれか。
# 延期の場合は status の後に追跡 Issue の参照 (#144 など) と説明を書き、必要に応じて補足を書きます。
# 末端サブコマンドごとの E2E 状況。1行1コマンドで、<path> <status> の順に書きます。
# 詳細は docs/design/live-e2e-coverage.md を参照。
